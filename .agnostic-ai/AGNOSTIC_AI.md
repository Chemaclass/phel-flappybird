# phel-flappybird

CLI Flappy Bird written in Phel (a Lisp that compiles to PHP, PHP 8.4+). Source in `src/`, tests in `tests/`.

- Install: `composer install`. Run from source: `composer dev`. Compile and play: `composer start`.
- Tests: `composer test`. Format check: `composer format-check`. CI gate: `composer ci` (format-check, test, build).
- Release PHAR: `composer phar`. See the rules under `.agnostic-ai/rules/`.
